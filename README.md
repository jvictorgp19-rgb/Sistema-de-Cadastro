# Sistema de Cadastro de Alunos

Sistema de cadastro de alunos via terminal.

## O que faz
- Cadastra nome e nota de múltiplos alunos
- Calcula automaticamente se o aluno foi aprovado ou reprovado
- Exibe relatório formatado com média geral da turma

## Tecnologias
- Java

## Como rodar
1. Clone o repositório
2. Abra no IntelliJ IDEA
3. Execute a classe `SistemaCadastro`
